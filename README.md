
# Panel & Parcel

## About the Project

Panel & Parcel is an online store I created for merchandise inspired by original characters from my webtoon, Fae Realm. The idea behind this website is to give fans a place where they can find items connected to the characters and stories they enjoy.

The store features products like shirts, hoodies, art prints, stickers, keychains, and other collectibles. I wanted the website to have a fun and creative design while also being easy for people to use.

**Live Website:** [View Panel & Parcel](https://mariah-llopez.github.io/Mariah-Lopez-panel-and-parcel/)

## Website Features

I created several pages and features to make the website feel like a real online store.

- **Home Page:** Introduces the store and shows some of the featured products.
- **About Us Page:** Shares the story behind Panel & Parcel and why I wanted to create it.
- **Shop Page:** Allows visitors to browse products, search for items, filter by category, and sort the collection.
- **Shopping Cart:** Gives visitors a way to keep track of the items they want.
- **Checkout Page:** Includes a sample checkout form where visitors can enter shipping information and review their order total.
- **Contact Page:** Provides store contact information, hours, and a location map.

The checkout is only a demonstration, so no real payments or orders are processed.

## Tools and Technologies Used

I used the following tools to build this website:

- **HTML:** To create the structure and content of each page.
- **CSS:** To style the website, including colors, fonts, images, and layouts.
- **JavaScript:** To add interactive features like searching, filtering, and shopping cart functions.
- **GitHub:** To store and manage my project files.
- **GitHub Pages:** To publish my website so others can view it online.

## What I Learned

Working on Panel & Parcel helped me better understand how HTML, CSS, and JavaScript work together to create a website. I learned how to organize multiple pages, design a layout, and add features that make a website more interactive.

One of the biggest parts of this project was making sure the different pages worked together and that visitors could easily move around the site. I also got more practice fixing problems, testing features, and making changes to improve the design.

## Future Improvements

There are still some features I would like to add in the future. These include adding more products, improving the shopping experience, and eventually connecting the store to a real checkout system.

I would also like to keep improving the website's design and making it easier to use on different screen sizes.

## Final Thoughts

Overall, I enjoyed creating Panel & Parcel because it allowed me to combine my interest in art and storytelling with web development. This project helped me practice my coding skills while building something based on my own creative ideas. I'm proud of what I created and look forward to improving it as I continue learning.
